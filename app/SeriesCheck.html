🔎 시리즈 누락 점검

우리 학교 소장도서에서 시리즈를 찾아, 빠진 권과 새로 나온 후속권을 알려 드립니다.

  1. 1
    아래 「점검 시작」을 누릅니다소장도서의 시리즈를 찾고 YES24에서 빠진 권을 확인합니다.
  2. 2
    잠시 기다립니다오래 걸리면 중간에 멈췄다가 약 1분 뒤 저절로 이어서 점검합니다. 창을 닫아도 됩니다.
  3. 3
    「시리즈 누락 점검」 표에서 고릅니다사고 싶은 책을 체크하고 「구입 검토함으로 보내기」를 누르세요.
상태를 확인하는 중…

YES24 API 키가 필요합니다. 없으면 「⚙️ 사본 설정 → 🔑 API 키 설정」에서 먼저 입력해 주세요.

💡 출판사는 적지 않아도 됩니다. 소장도서의 ISBN 으로 YES24 에서 자동으로 확인해 같은 이름의 다른 출판사 책이 걸리는 일을 줄입니다.
