🔎 시리즈 누락 점검

빠진 권과 새 후속권을 찾아 드립니다
상태를 확인하는 중…
-소장도서(권)
-지금 표에 있는 후보(권)
사용 방법 · 알아 두실 점
  1. 「점검 시작」을 누르면 소장도서의 시리즈를 찾아 YES24에서 빠진 권을 확인합니다.
  2. 오래 걸리면 중간에 멈췄다가 1분 뒤 저절로 이어갑니다. 이 창을 닫아도, 시트를 닫아도 계속됩니다.
  3. 진행 상황은 시트 「시리즈 누락 점검」 맨 위 줄에도 같은 내용이 뜹니다.
  4. 끝나면 표에서 살 책을 체크하고 「구입 검토함으로 보내기」를 누르세요.
  5. YES24 API 키가 필요합니다. 없으면 「⚙️ 사본 설정 → 🔑 API 키 설정」에서 입력하세요.
  6. 출판사는 적지 않아도 됩니다. ISBN 으로 YES24 에서 자동으로 확인합니다.
