🔗 신청 링크 받기

누구에게 보낼 링크인지 골라서, 복사하거나 QR 그림으로 저장하세요.

먼저 웹 앱을 한 번 배포해야 링크가 만들어져요.
  1. 위쪽 「확장 프로그램」 → 「Apps Script」를 누르세요.
  2. 새 화면 오른쪽 위 「배포」 → 「새 배포」 → 톱니바퀴(유형 선택) → 「웹 앱」을 고르세요.
  3. 실행 사용자는 「나」, 액세스 권한은 「모든 사용자」로 하고 「배포」를 누르세요.
  4. 끝나면 이 창을 닫고, 「⚙️ 사본 설정 → 🔗 신청 링크 받기」를 다시 누르세요.

이미 배포했는데도 이 안내가 나오면, 「⚙️ 사본 설정 → 🔗 공개 링크 등록」에 /exec 주소를 붙여 넣은 뒤 다시 눌러 보세요.

⚠️ 지금 등록된 주소로는 접속이 안 돼요

현재 등록된 주소:

  1. 위쪽 「확장 프로그램」 → 「Apps Script」 → 「배포」 → 「배포 관리」를 여세요.
  2. 웹 앱의 주소(…/exec)를 처음부터 끝까지 복사하세요.
  3. 시트에서 「⚙️ 사본 설정 → 🔗 공개 링크 등록」에 붙여 넣고 저장하세요.
  4. 다시 「🔗 신청 링크 받기」를 누르면 QR이 만들어져요.
✅ 등록돼 있던 주소가 열리지 않아서, 지금 배포된 웹 앱 주소로 자동으로 바꿨어요.
⚠️ 「공개 링크 등록」에 저장된 주소를 쓰고 있어요. 이 주소가 지금 배포한 웹 앱과 다르면 링크가 안 열릴 수 있어요. 그럴 때는 Apps Script 「배포 → 배포 관리」에서 현재 웹 앱 주소를 복사해 「공개 링크 등록」에 다시 붙여 넣어 주세요.

학부모님께 보내는 링크예요. 이 링크로 들어가면 교직원 화면은 보이지 않아요.
